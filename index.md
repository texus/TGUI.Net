**TGUI.Net** is a .NET binding for the [TGUI library](https://tgui.eu) (a cross-platform GUI library), for use in combination with [SFML.Net](https://github.com/SFML/SFML.Net/).

The library targets **.NET Standard 2.1** and supports **Windows**, **Linux** and **macOS**.
