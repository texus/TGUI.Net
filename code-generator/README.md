Updating generated files
------------------------

Some files or parts of files are generated from templates to reduce the amount of boilerplate code that needs to be written.

Simply run the `GenerateCodeCSharp.py` script to regenerate all such files. The output is written directly to the `src` directory from the root folder. This is already done during development, so you only need to generate code when making changes to CTGUI, you don't need it when simply using CTGUI in your project.
