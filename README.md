TGUI.Net
========

[TGUI.Net](https://tgui.net) is a .NET binding for the [TGUI library](https://github.com/texus/TGUI) (a cross-platform GUI library), for use in combination with [SFML.Net](https://github.com/SFML/SFML.Net/)

The library is build for `.NET Standard 2.1`, so .NET Frameworks are not supported.

Check out the [example code](https://github.com/texus/TGUI.Net/blob/1.x/examples/login_screen/LoginScreen.cs) for information on how to use the library.

The `TGUI.Net` package can be found on [NuGet.org](https://www.nuget.org/packages/TGUI.Net/)
